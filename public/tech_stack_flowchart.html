Architecture Approach

TECHNICAL APPROACH FLOWCHART

TypeScript & React Architecture • Zero Cloud Cost • 100% Offline

LAYER 1

Frontend & Presentation Layer

React 18 • TypeScript • Tailwind CSS • Lucide Icons
  • Why React + TypeScript: Strict static type-safety prevents runtime crashes on low-cost school tablets.
  • Component Architecture: Modular tabs for Quick Translator, Digital Slate, Worksheets, and Audio Guides.
LAYER 2

Browser Hardware Interaction APIs

Web Speech API • HTML5 Canvas API • Touch / Stylus Events
  • Voice Capture (STT): Captures spoken Hindi directly through the device microphone with 0 ms server round-trip.
  • Digital Slate: 60 FPS HTML5 Canvas engine tracks student letter tracing with real-time accuracy scoring.
LAYER 3

In-Memory Core NLP Engine (Zero-Python Backend)

TypeScript Rule Engine • O(1) Hash Map • Unicode Range Matrix
  • Why NO Python: Python NLP models (PyTorch/Transformers) require 2–4 GB RAM and heavy servers.
  • TypeScript Advantage: In-memory dictionary compiles to <2 MB JavaScript bundle, executing in <1 ms.
  • Dual-Scripting: Simultaneously outputs Ol Chiki / Warang Chiti and Devanagari phonetic guide.
LAYER 4

Dual-Engine Speech Synthesis (TTS)

Web SpeechSynthesis API • Web Audio API Formant Synthesizer
  • Primary (TTS): Pre-warmed native speech synthesis on Android / Windows tablets.
  • Offline Fallback (DSP): Web Audio formant oscillator computes vocal cord physics directly in math (<400 ms).
LAYER 5

Offline-First Storage & Deployment Layer

Service Worker (sw.js) • Cache API • LocalStorage • CSS @media print
  • 100% Offline PWA: Service Worker caches all assets. The app installs to tablet home screen like a native APK.
  • Classroom Worksheets: Pure CSS print media renders high-res A4 printable worksheets without external PDF servers.
